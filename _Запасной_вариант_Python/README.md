# Запасной вариант: реализация на Python

Здесь лежит первая редакция учебных проектов курса, сделанная на Python и FastAPI.

## Почему она здесь

Проекты готовились до того, как заказчик прислал состав группы. Исходное допущение было, что
основной язык студентов Python. Фактически группа это четвёртый курс направления
«Web-программирование и разработка ПО»: C# и .NET, ASP.NET Core, JavaScript, React, Angular, PHP.
Python в их подготовке отсутствует.

Поэтому основной комплект курса переведён на TypeScript и Node.js, а эта версия сохранена
как запасная.

## Когда она может понадобиться

- Если на месте выяснится, что группа собрана из другого потока и Python им ближе
- Если у части студентов не заработает окружение Node.js, а Python окажется под рукой
- Для следующих потоков курса с другой аудиторией

## Что внутри

| Папка | Что это |
|---|---|
| `booking-reference-python/` | Эталонный сервис бронирования: TypeSpec, FastAPI, SQLite, фронтенд без сборки, тесты pytest, Docker, GitHub Actions, ADR, PDR, онтология. 69 тестов проходят |
| `legacy-demo-python/` | Учебный проект модуля 7: намеренно плохо написанный, но рабочий скрипт отчётности, характеризующие тесты, эталонный вывод, папка `after/` с результатом рефакторинга, сверка версий. 18 тестов проходят |

Обе версии полностью рабочие и проверены запуском. Инструкции внутри их файлов `README.md`.

## Важно

Учебные материалы курса (раздатки, конспект, презентации, тест) написаны под основную версию на
TypeScript. При переходе на запасной вариант примеры кода в материалах перестанут совпадать
с проектами.
