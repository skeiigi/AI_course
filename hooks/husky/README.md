# Husky-обёртки

Эти файлы лежат здесь как **заготовка** для будущей миграции на
[husky](https://github.com/typicode/husky). Они не активируются сами по
себе — чтобы они заработали, нужно:

```bash
npm install --save-dev husky
npx husky install .husky   # при условии, что ты скопировал эту папку в <repo>/.husky
```

После этого `git commit` / `git push` будут вызывать husky, который найдёт
`.husky/pre-commit` / `.husky/commit-msg` / `.husky/pre-push`, а те, в свою
очередь, запустят соответствующие скрипты в `../hooks/`.

Логика хуков при этом не дублируется — единый источник правды остаётся
в `hooks/`.

Если husky тебе не нужен — просто не копируй эту папку в свой репозиторий.
Прямые хуки из `hooks/` работают без husky.
