# PDR 0002. Доступ к брони по секретной ссылке

- **Статус:** принято
- **Дата:** 6 октября 2026

## Проблема

Открытый список броней раскрывал имена и адреса почты всех гостей. Адрес почты
не подтверждает владение бронью, а числового идентификатора хватало для отмены.

## Решение

После создания гость получает отдельную секретную ссылку на бронь. Браузер
сохраняет ссылки на созданные и открытые в нём брони и показывает их в разделе
«Мои брони». Ссылку можно скопировать сразу после создания или позже из списка.
На другом устройстве гость открывает сохранённую ссылку.
Просмотр и отмена требуют секрет этой брони. Общего списка броней и поиска по
почте в открытом API больше нет.

Учётные записи, почтовая проверка и панель организатора в этой версии не
добавляются. Административный просмотр всей истории потребует отдельной модели
доступа. Секретную ссылку нужно сохранить: восстановить её по одному адресу
почты нельзя.

Для броней, созданных до этого решения, оператор может вручную выдать секретную
ссылку после проверки владельца. API не восстанавливает ссылки автоматически.

Это решение заменяет доступ по почте, описанный в PDR 0001. Техническая схема
записана в ADR 0004.
