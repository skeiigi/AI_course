# PDR 0003. Бронирование нескольких слотов

- **Статус:** принято
- **Дата:** 6 октября 2026

## Задача

Гостю может потребоваться несколько встреч одной активности. Повторять форму
для каждого слота неудобно.

## Решение

Гость выбирает до 20 свободных слотов одной активности, в том числе в разных
неделях, и вводит контактные данные один раз. Повторное нажатие на выбранный
слот снимает выбор. Один запрос создаёт отдельную бронь и отдельную секретную
ссылку для каждого слота. Ссылки сохраняются в браузере и доступны в разделе
«Мои брони». Отмена одной брони не затрагивает остальные.

Вместо нажатий на слоты гость может ввести дату, время начала и окончания.
Интервал должен целиком покрываться существующими свободными слотами
расписания. Подходящие слоты автоматически выделяются в календаре, в том числе
если для интервала требуется несколько слотов. При несовпадении границ,
пробеле в расписании или занятом слоте интерфейс объясняет причину отказа.
Произвольное время вне расписания не бронируется.

Перед отменой отдельной брони интерфейс показывает её дату и время и просит
подтвердить действие. Отказ от отмены ничего не меняет.

Если хотя бы один слот недоступен, не создаётся ни одна бронь из набора. Гость
получает сообщение об ошибке и может обновить выбор. Групповая операция
выполняется атомарно в SQLite; одиночное бронирование остаётся доступным.

Техническая схема описана в `docs/adr/0005-atomarnoe-gruppovoe-bronirovanie.md`.
