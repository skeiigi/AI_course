# PDR 0004. Страница брони и переписка перед встречей

- **Статус:** принято
- **Дата:** 7 октября 2026

## Решение

Секретная ссылка открывает отдельную страницу брони с её датой, временем,
статусом и перепиской. Гость может передать ту же ссылку организатору. Оба
видят сообщения и могут написать ответ. Учётных записей, автоматической
доставки ссылки и подтверждения личности в этой версии нет: имя отправителя
он указывает сам, и сайт не подтверждает, кто именно написал сообщение.

Переписка доступна только по секрету конкретной брони. Сообщения сохраняются
после отмены для истории, но писать новые можно лишь пока бронь действует и
встреча ещё не началась по времени Красноярска. Текст сообщения ограничен
2000 символами, отображается только как обычный текст.

Обновление сообщений выполняется при открытии страницы, после отправки и
периодически, пока страница открыта. В этой версии нет доставки в реальном
времени и уведомлений вне страницы.

Общая ссылка также даёт право отменить бронь согласно PDR 0002. Передавать её
следует только участникам встречи. Это расширяет сценарий PDR 0002, который
изначально не предусматривал организаторский интерфейс и переписку.
